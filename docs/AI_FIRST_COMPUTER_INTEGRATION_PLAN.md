# Final Implementation Plan — Any Model Drives the Computer, Truthfully

## 1. Thesis

The infrastructure for the north star — "any model, auto-routed or hand-picked, drives browser/desktop/app work from Chat" — already exists in finished-but-dark seams: the edge relay translates Anthropic tool shape for 15+ providers (`swanbot-ai/index.ts:3513-3666`), the stream→escalate seam is wired and default-ON (`chatTerminalTransportPolicy.ts:85-94`, `ChatTab.tsx:8337-8467`), and a dozen pure decision modules (aiFirstChatPolicy, modelCollaborationPolicy, hostedBlackSwanInvocation, failover chains, surface readiness) are built but decorative. The month's leverage is therefore not new systems. It is, in strict order: **(1)** restore a green, trustworthy release gate and close the approval-bypass holes so every later friction cut is provably safe; **(2)** demolish the model wall by routing action-shaped marketplace turns through the existing relay tool loop instead of the text-only tier that makes GPT/Gemini/DeepSeek confidently lie about actions, with honest prompts, full output tokens, and visible (never silent) substitutions; **(3)** make every running thing — escalated turns, edge browser agents, 50-agent deploys — visible, attributable, and cancelable; **(4)** unify the three disconnected approval economies and un-starve the tool palette so a user's grant actually buys friction reduction where execution happens; **(5)** flip the dead seams live (hosted BlackSwan-v5, failover, surface readiness, recovery fidelity, orchestration-policy convergence) and give the opt-in v2 loop memory, gates, and budgets — without any default flip. Every phase ships independently; all logic lands in pure lib owners with smoke coverage, keeping the 20k-line, partially root-owned ChatTab.tsx thin.
