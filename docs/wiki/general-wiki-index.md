## File conventions

- evergreen docs should be broad and stable
- dated docs should include the full date in the filename
- every dated report should end with a source list
- every report should state whether it is evergreen or time-sensitive

## Maintenance rule

When a topic is durable, update the evergreen doc.

When a topic reflects a moment in time, add a dated report and link it from here.
