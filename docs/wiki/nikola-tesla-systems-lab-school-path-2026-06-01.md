# Nikola Tesla Systems Lab School Path

Last updated: 2026-06-01

Status: dated curriculum blueprint for the wiki and future Schools integration.

## Purpose

This school path turns Tesla's work into safe, useful systems learning. It should teach students how electricity becomes useful work, how motors and grids shape daily life, how wireless systems really behave, how remote control becomes robotics, and how to separate evidence from myth.

The path should feel inspiring, but it must stay safe and measurable.

## Learning goals

By the end, learners should be able to:

- explain the difference between energy source, transmission, conversion, and useful work
- describe why AC power, transformers, and motors changed infrastructure
- identify where motor systems waste energy
- distinguish wireless communication from wireless power
- explain why high-voltage and RF experiments need strict safety boundaries
- design a simple remote-control workflow with fail-safes
- classify Tesla claims by evidence quality
- propose a small project that improves energy, communication, safety, or resilience

## Lesson 1: Energy Source To Useful Work

Core idea: energy projects should be judged by useful work, not spectacle.

Activities:

- map a familiar load: light, fan, pump, refrigerator, scooter, phone charger, computer
- trace source, transmission, conversion, storage, control, and end use
- label losses and safety boundaries
- discuss how cleaner electricity changes the impact of the same load

Output:

```text
Source:
Transmission path:
Conversion device:
Useful work:
Losses:
Safety boundary:
Improvement idea:
```

## Lesson 2: AC Power And Rotating Magnetic Fields

Core idea: Tesla's induction motor breakthrough was not magic. It used electromagnetic fields to produce motion without brushes or commutators.

Activities:

- use an animation or low-voltage model to show rotating fields
- compare fixed-speed and variable-speed control conceptually
- identify where motors appear in a building or home

No high-voltage demonstration is required.

Output:

- sketch of input electricity to rotating field to useful motion
- list of five motors in daily life
- one question about efficiency or maintenance

## Lesson 3: Motor Audit Walkthrough

Core idea: climate improvements can start with hidden machines.

Activities:

- use the motor audit kit on a visible safe load
- estimate runtime and load type
- identify whether demand is constant or variable
- make a safe recommendation: observe, maintain, meter, review controls, or ask a qualified expert

Output:

- one completed motor audit summary
- one safety warning
- one data field that needs measurement

## Lesson 4: Grid Resilience And Microgrids

Core idea: the grid is an operating system for public life.

Activities:

- choose a site: school, clinic, farm, apartment building, town hall, emergency shelter
- list critical loads during an outage
- rank loads by life/safety, communication, water, food, heat/cooling, education, and comfort
- design a simple resilience plan using grid power, battery, solar, generator, demand reduction, and communication

Output:

```text
Critical loads:
Outage scenario:
Available resources:
First 24-hour plan:
72-hour plan:
Weakest point:
Improvement:
```

## Lesson 5: Wireless Communication Versus Wireless Power

Core idea: information is cheap to move wirelessly compared with useful power.

Activities:

- compare Wi-Fi, radio, Bluetooth, cellular, and satellite as communication systems
- compare inductive charging, resonant charging, and power beaming as power systems
- discuss efficiency, alignment, interference, safety, regulation, and receivers

Output:

| System | Moves information or power? | Range | Main risk | Good use |
| --- | --- | --- | --- | --- |
| Wi-Fi | information | local | privacy/interference | internet access |
| inductive charger | power | very short | heat/alignment | phone/tool charging |
| power beaming | power | specialized | aiming/exposure/weather | controlled remote systems |

## Lesson 6: Remote Control And Robotics Safety

Core idea: remote control can keep people out of danger, but only with fail-safes.

Activities:

- design a remote inspection task for a bridge, roof, solar farm, power line, crop field, flood zone, or tunnel
- define observe, decide, act, stop, and recover steps
- add fail-safes: geofence, emergency stop, battery reserve, communication-loss behavior, human override

Output:

```text
Inspection target:
Why remote operation helps:
Robot/drone/sensor:
Human operator:
Fail-safes:
Evidence collected:
Stop condition:
```

## Lesson 7: Tesla Claim Triage

Core idea: curiosity is stronger when it has evidence rules.

Activities:

- choose one Tesla claim
- classify it using the claim checker
- identify source type and evidence gaps
- decide whether to use, study, prototype cautiously, reject, or escalate to an expert

Output:

- claim class
- primary source
- what was actually built
- what was measured
- final decision

## Lesson 8: Planetary Benefit Project

Core idea: the best Tesla-inspired project improves life in a measurable way.

Project choices:

- motor-system savings plan
- microgrid resilience plan
- emergency communication kit
- safe wireless-power comparison
- remote inspection workflow
- public science demonstration
- Tesla myth-busting source review


## Teacher and agent guidance

- keep the first screen on the real activity, not a biography lecture
- use historical Tesla context only to explain the system being studied
- do not ask students to build high-voltage Tesla coils
- use simulations before hardware
- require source lists for claims
- treat local facilities as living systems: energy, safety, maintenance, people, cost, and resilience
